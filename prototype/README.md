# 广莫交互原型

用浏览器打开 `index.html`，无需安装依赖。图标和 Logo 均为本地资源。

## 可体验范围

- 对话、项目、发展方向、每周回看、记忆页面。
- 固定 52px 图标侧栏，不提供展开／收起操作，顶部直接显示导航入口。
- 点击侧栏第一个“对话”图标，在侧栏右侧打开会话列表；宽屏并排显示，窄屏浮层显示，可再次点击、按 Escape 或使用关闭按钮收起。
- 会话列表顶部可新建会话；下方按「置顶」「项目」「最近」分组展示示例条目，分类内容在同一区域滚动。
- 原型使用紧凑间距，触摸设备保留较大的会话点击区域。
- 对话页顶部保留新建、历史入口，历史入口打开同一列表；历史条目目前将示例主题填入输入框，并非恢复真实历史。
- Enter 发送、Shift + Enter 换行、中文输入法组词保护。
- 亮暗主题切换与本地保存；上下文选择、附件文件名展示。
- 圆角矩形统一采用连续曲率风格；支持 `corner-shape` 的浏览器显示平滑转角，否则回退为普通圆角。
- 项目下一步弹窗、回看反馈、记忆确认和删除演示。

## 边界

未接入模型、账户、数据库或外部日历。对话是固定示例回复；附件不会上传或读取。除主题外，交互结果仅在本次页面会话内保留。学习入口目前仅为对话提示，学习计划闭环待开发。
