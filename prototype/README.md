# 广莫交互原型

浏览器打开 [index.html](index.html)；[components.html](components.html) 为组件展示页，无需安装依赖。Phosphor regular／fill 图标通过 jsDelivr 加载固定版本 `@phosphor-icons/web@2.1.2`，需要联网；Logo 使用本地资源。

设计要求见[设计系统](../design/design-system.md)，对话交互与待确认项见[页面规范](../docs/对话页面规范.md)。

## 能力与限制

- 组件展示页已移除独立的「菜单」示例及其专用样式和事件处理。
- 可体验对话、会话列表、项目、发展方向、回看、记忆，以及学习资料、伴读、划线、笔记和产物演示。
- 未接入真实模型、账户、服务端数据库或日历。历史条目只填入示例主题，生成结果为模拟内容，学习计划闭环未实现。
- 主对话附件仅显示文件名；学习 TXT 和粘贴内容在本地读取，PDF 模拟解析，不上传。
- 主题和部分学习数据存于浏览器。圆角、主题扩散按浏览器能力回退。
- 对话顶栏已隐藏，DOM 仍有旧的新建与历史按钮。

共享样式位于 `ui.css`，补充变量位于 `theme.css`，主题动画位于 `theme.js`；其余 CSS 在低优先级 `prototype` 层维护布局。

## 验证状态

- **弹窗玻璃效果**：组件展示页面板接入半透明背景与背景模糊，遮罩模糊尺度集中到变量；随亮暗主题取色，不支持模糊或要求减少透明效果时面板回退实色。静态差异检查通过，浏览器视觉、文字对比度与回退效果未验证。
- **滑块外观调整**：轨道与进度条保持相同视觉尺度，拖动圆点使用强调色填充、表面色外圈与轻投影，数值使用辅助字号，点击区域按紧凑／触屏规格。静态差异与脚本语法检查通过；浏览器拖动、键盘及亮暗主题效果未验证。
- **进度条外观调整**：已接入更细的高度、辅助字号百分比、无描边及轨道与填充全圆角样式，具体尺度见设计系统，覆盖 WebKit／Chromium 与 Firefox 原生进度条；静态差异检查通过，各浏览器亮暗主题视觉效果未验证。
- **静态**：已有语法、资源、重复 ID、CSS、变量及差异检查；最近改动已检查相关语法、选择器和层级。
- **此前浏览器检查**：桌面首页、会话列表、学习／伴读切换、划线弹窗、部分文本框、工作台标签和日期选择器；不代表当前版本已回归。
- **下拉尺寸调整**：短选项的可用／禁用示例统一宽度，展开选项的高度与上下留白小于触发器，两者分别使用尺寸变量，选项之间保留间隔；触屏仍使用触屏最小高度，具体尺度见设计系统。已做静态差异检查；浏览器策略阻止本地文件预览，视觉与交互未验证。
- **待验收**：最近控件、禁用、排版与动效修改；完整亮暗主题、刷新恢复、资源、对比度、键盘／输入法、手机／触屏和长内容滚动。
- **标签页调整**：展示页按钮使用独立的紧凑高度，减少上下留白，触屏保留触屏最小高度；按钮各状态无描边，保留键盘焦点提示；切换时选中底块滑动并适配目标尺寸，减少动态效果模式下直接切换，具体规则见设计系统。静态差异检查通过，视觉与切换交互未验证。

按[验收要求](../design/design-system.md#11-验收要求)记录结果。原型验证不代替正式应用验收。
