# 广莫交互原型

用浏览器打开 `index.html`，无需安装依赖。功能图标通过 jsDelivr 加载固定版本 `@phosphor-icons/web@2.1.2` 的 regular 与 fill 字体样式，需要联网；Logo 仍为本地资源。

本文仅记录原型能力与限制，不作为正式应用的设计确认或验收记录。全局要求与待实现项见[设计系统](../design/design-system.md)，会话列表、入口组合、滚动结构和发送按钮的确认状态见[对话页面规范](../docs/对话页面规范.md)。

## 可体验范围

- 对话、项目、发展方向、每周回看、记忆页面。
- 固定 52px 图标侧栏，不提供展开／收起操作，顶部直接显示导航入口。
- 点击侧栏第一个“对话”图标，在侧栏右侧打开会话列表；宽屏并排显示，窄屏浮层显示，可再次点击、按 Escape 或使用关闭按钮收起。
- 会话列表顶部可新建会话；下方按「置顶」「项目」「最近」分组展示示例条目，分类内容在同一区域滚动。
- 原型使用紧凑间距，触摸设备保留较大的会话点击区域。
- 历史条目目前将示例主题填入输入框，并非恢复真实历史。
- Enter 发送、Shift + Enter 换行、中文输入法组词保护。
- 亮暗主题切换与本地保存；工作台和组件展示页的入口均位于侧栏底部。可体验上下文选择、附件文件名展示。
- 圆角矩形统一采用连续曲率风格；支持 `corner-shape` 的浏览器显示平滑转角，否则回退为普通圆角。
- 对话页大输入框使用 `--radius-composer`，圆角大小已确认，遵循[设计规范第 6 节](../design/design-system.md#6-圆角边框与阴影)；正式应用的实现状态以设计规范为准。
- 项目下一步弹窗、回看反馈、记忆确认和删除演示。

## 入口现状与差异

- DOM 中仍保留顶部新建、历史按钮；[home.css](home.css) 隐藏了对话页顶栏，因此这两个顶部入口在对话页不可见。侧栏对话入口和会话列表内的新建入口仍保留。
- 新建与历史入口的正式组合仍待确认，见[对话页面规范](../docs/对话页面规范.md#新建与历史入口)；主题入口已移至侧栏底部，见[设计系统第 3 节](../design/design-system.md#3-颜色与主题)。

## 边界

未接入真实模型、账户、服务端数据库或外部日历。主对话是固定示例回复，会话列表是示例数据；主对话附件仅展示文件名，不会上传或读取。主题选择及部分学习演示数据已有浏览器本地保存，不能据此认定已接入服务端持久化。学习入口已有阅读、笔记及资料工作台等演示，真实学习计划闭环仍待开发。

## 样式组织与接入状态

- 功能图标使用 CDN 的 `ph` / `ph-fill` 类，导航选中、主题和收藏状态沿用原有切换逻辑；不再依赖本地 Phosphor SVG 或内嵌路径。

- `theme.css` 引用正式 `tokens.css` 的排版、间距和布局尺度，维护原型已确认的输入色、轻投影及正式应用尚未接入的语义变量。
- `ui.css` 统一工作台与组件展示页的字体、输入、按钮、焦点、状态、圆角和触屏尺寸；`workspace.css`、`samples.css`、`home.css` 在低优先级 `prototype` 层维护页面布局与演示结构。
- 阅读页已移除宋体，统一系统无衬线字体；对话与阅读、输入文字、标题、辅助信息按设计系统映射。
- 非选中背景、头像、引用高亮、滚动条、按下及禁用配色已接入专用语义变量；这些是源码接入记录，不代表实际对比度通过验收。
- 原型圆角、边框、焦点、列表密度与动效变量位于 `theme.css`；`--radius-composer` 已从 HTML 移至此处。聊天输入区容器使用独立焦点轮廓，单行文本输入框（含搜索框）与独立多行文本框不显示常态或焦点描边，上传区和引用块使用常规实线边界。
- 响应式断点按设计规范对齐，聊天输入区由外层承担手机底部安全区；真实设备效果仍待验收。
- 主题扩散由 `theme.js` 统一处理；减少动态效果时直接切换，不支持相应浏览器能力时渐进回退。
- 学习页使用多栏工作区，保留宽布局；阅读正文内部限宽用于双栏阅读。画布、进度条、日历网格等内容尺寸属于专用布局，不套用通用列表高度。
- 会话展开、新建与历史入口组合、滚动结构和发送按钮形态继续保留现有演示，不将业务待确认方案视为已确认设计。

工作台标签状态已集中至 `ui.css`，覆盖学习模式、伴读对话／学习笔记和小屏原文／伴读切换，遵循[设计系统标签页状态](../design/design-system.md#标签页状态)。按下边界通过不占布局的内侧伪元素绘制，保留原有尺寸、圆角和键盘焦点。已在 Chrome 桌面检查亮暗主题的悬停、选中与焦点显示，以及 Tab、Enter、Space 切换；按下边界完成静态检查，小屏与触屏效果仍待验收。

### 组件库展示布局

- 桌面采用左侧组件名称、右侧示例的对齐布局，以间距与轻分隔线区分组别；窄屏改为标题在上、示例在下。
- 尺寸示例统一间距与底部对齐，输入示例统一展示宽度；不修改共享控件外观和交互。
- 本次通过 diff 空白检查；浏览器不允许打开本地文件，资源加载、亮暗主题、窄屏布局及交互尚未完成浏览器验证。

- 复选框改为 Phosphor 标准勾形，外框比例遵循[设计系统复选框条目](../design/design-system.md#复选框)。保留原生输入与标签交互；本轮完成静态结构检查，浏览器视觉及键盘验证仍待完成。

- 禁用控件背景按设计系统的用途映射维护；同步弱化选择项标签，不额外附加禁用状态文案，修复禁用次级按钮悬停反馈及开关选中样式覆盖禁用配色的问题。补充单选、开关（开／关）、下拉与多行输入禁用示例。共享禁用背景也影响工作台已有禁用控件；浏览器视觉与交互验证仍未完成。

- 开关几何与状态样式集中至 ui.css：圆点绝对定位垂直居中、两端留白对称，清除原先外距与原生 padding 的影响；禁用开／关分别使用对应轨道背景并保留圆点位置。尺寸由 theme.css 维护，标签与轨道对齐。已完成静态检查，浏览器验证仍待完成。

- 禁用输入区域改用独立的 `--disabled-input-bg`，恢复浅色与暗色页面上的可见底色，覆盖组件页单行、多行和选择框的默认／悬停状态；按钮与开关保持原配色。静态检查通过，浏览器视觉效果待验收。

- 组件页字号按设计系统排版映射统一：降低左侧分类标题的字号与字重，日期选择、下拉当前值与选项、单行及多行输入统一使用控件字号，简短标签页状态及消息提示使用控件字号；修正紧凑表格、工具提示与菜单触发器，并清理独立文字尺寸和标题过紧字距。紧凑及禁用状态不缩小文字，图标字号保持独立。静态检查通过，浏览器视觉验收待完成。

- 组件展示页已修复标签页悬停时通用按钮背景遮盖选中底块的问题；状态样式集中于 ui.css，悬停仅改变文字色，按下使用稳定宽度的边界反馈，保留原有键盘焦点与切换逻辑。静态检查通过，组件展示页的浏览器效果待验收；工作台标签的验证范围见上文。

- 组件展示密度按[设计系统](../design/design-system.md#组件展示页密度)调整：统一单行控件高度及水平留白，标签与输入间距更清晰；普通多行示例减少空高但保留内边距，标签页底槽随内容收窄，组间留白收拢，表格保留可读行高。既有字号、禁用颜色和开关几何不变。静态检查通过，亮暗主题、窄屏与交互仍待浏览器验收。

- 日期选择器的选中、悬停与按下配色集中至 `ui.css`，复用设计系统的前景背景配对，避免通用按钮悬停样式覆盖选中背景；移除 `samples.css` 中重复的日期状态规则。已在 Chrome 桌面原型检查亮暗主题下的选中悬停效果，以及方向键移动、Enter 选择和 Escape 收起后的焦点恢复；按下配色完成静态检查，触屏与窄屏效果仍待验收。
