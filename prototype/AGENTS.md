# 原型开发规范

## 外部依赖与规范

- 第三方库、字体、图标及其他公共资源，只要支持通过网络链接引入，就必须使用网络链接。
- 优先使用官方提供或官方推荐的 CDN 地址。
- 支持版本号的依赖必须固定版本，不使用 `latest` 或省略版本号的地址。
- 不将可通过网络引入的资源下载、复制、导出或内嵌到项目中，也不新增本地副本作为回退。
- 项目自身代码、自有 Logo 和业务素材保留本地文件。
- 不支持网络引入的必要资源，可以使用本地文件，并在 README 中说明原因。

## 设计与验证

- 视觉和交互遵循 `../design/design-system.md`，不在此重复定义。
- 原型实现状态、使用限制和验证记录维护在 `README.md`。
- 修改后在浏览器中检查资源加载、页面布局和相关交互；未验证的项目必须明确记录。
