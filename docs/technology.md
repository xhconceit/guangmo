# 广莫技术栈总览

> 本文区分已实际接入的技术与后续规划，避免把设计方案误当成当前实现。



## 1. 当前阶段

广莫当前目标是完成整体产品骨架与模拟对话体验。

本阶段不接入真实 AI、数据库、认证、外部连接器或后台任务。优先验证页面结构、核心交互和业务模型边界。

## 2. 当前技术栈

| 类别 | 技术 | 用途 |
| ---  | ---  | ---  |
| 编程语言 | TypeScript | 前端、领域模型和服务接口的统一语言 |
| 页面结构 | HTML | 由 React 与 Next.js 生成页面结构 |
| 样式 | CSS | 视觉样式、设计令牌和亮暗主题 |
| 前端框架 | React | 组件与交互状态 |
| Web 框架 | Next.js App Router | 页面路由、共享布局与未来的服务端接口 |
| 工程管理 | pnpm workspace | 管理应用与共享包 |
| 图标 | Lucide React | 功能入口与界面图标 |
| 领域模型 | `packages/domain` | 对话、项目、记忆、方向、回看等核心业务类型与规则 |
| 前端服务 | `apps/web/src/services` | 定义 UI 获取、保存业务数据的接口；当前使用模拟实现 |
| 数据来源 | 内存 mock 数据 | 支持开发阶段的页面与交互验证 |

## 3. 代码结构与职责

```text
apps/web
├── src/app                 # 路由、页面和共享布局
├── src/components          # 跨功能复用的界面组件
├── src/features            # 按业务功能组织的组件与交互
└── src/services            # 数据访问与业务服务接口

packages/domain
└── src                     # 不依赖 React、Next.js 或数据库的业务类型和规则
```
