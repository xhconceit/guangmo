# 对话页面规范

通用视觉、控件、响应式与无障碍遵循[设计系统](../design/design-system.md)，原型能力与验证见[原型说明](../prototype/README.md)。

## 已确认要求

| 项目 | 要求 |
|---|---|
| 宽度 | 最大宽度 `--conversation-width`，值见正式 tokens.css；内边距和手机安全区按设计系统 |
| 输入 | 组词期间 Enter 仅确认候选词；其他情况 Enter 发送、Shift + Enter 换行；空白不发送 |
| 会话列表 | 点击侧栏对话图标展开，按置顶／项目／最近分组 |
| 新建与历史 | 隐藏对话顶栏；侧栏打开列表访问历史，列表顶部新建，不提供顶部新建或历史按钮 |
| 滚动 | 有消息时记录区独立滚动，输入区留在底部；消息增长、视口变化不产生额外页面滚动 |
| 输入高度 | 随内容增高、删除后缩回；增高压缩消息区，达到上限后输入框内部滚动 |
| 图标 | 新建 `plus-circle`、附件 `plus`、关闭列表 `x`、发送 `arrow-up` |
| 发送按钮 | 胶囊形底块，提供“发送”可访问名称 |

## 正式应用缺口

- 宽度硬编码与变量同值，待接入变量及工具类。
- 发送仅打印内容并清空草稿，未接入真实对话。
- 侧栏仅路由导航，列表与列表内新建待实现。
- 外层 main 滚动，独立消息区、底部输入布局和手机安全区待实现。
- 发送仍为文字胶囊按钮，待换箭头图标。

以上为源码现状，未完成浏览器验收。

## 待确认业务细节

- 列表是否宽屏并排、窄屏浮层。
- 分组标题与条目是否左对齐，分别用辅助／正文层级，不缩进、不加分隔线或大段空白。
- 新建入口是否无底色，使用正文色与悬停背景。
- 有草稿时是否先确认再新建。

确认前保持现状；确认后归入上表。页面按[全局验收要求](../design/design-system.md#11-验收要求)核对上述交互。
