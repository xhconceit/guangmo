## 1. 产品目标

帮助用户围绕自己提供的资料完成学习，减少查找、理解和整理信息所需的操作。

核心用户需求包括以下几项。

- 快速了解一本书的主要内容与章节关系。
- 理解难懂的概念和段落，并通过追问澄清疑惑。
- 找到回答所依据的原文。
- 将资料整理成可复习的学习材料。
- 保存学习过程，方便后续继续。
- 通过解释概念、回答理解题等方式检查学习效果。

### 1.1 与广莫现有规划的关系

广莫的 MVP 已包含学习目标、阶段拆解、每周安排、实践与复习、完成反馈及计划调整。本功能作为学习模块的候选扩展，补充资料阅读、原文问答与学习材料生成能力。

| 广莫已有规划 | 本功能的衔接建议 |
| --- | --- |
| 学习目标与关联项目 | 学习空间可关联用户已有的目标、项目或发展方向 |
| 学习任务与材料 | 从任务进入对应书籍、章节或资料，保留返回学习安排的入口 |
| 实践与复习 | 理解题、记忆卡和学习指南可成为任务材料或预期产出 |
| 完成反馈 | 分别记录阅读位置、用户完成反馈与理解检查表现 |
| 每周回看 | 汇总学习产出、仍有疑问的概念和用户反馈 |

学习计划调整先形成可修改的站内草稿；外部日历写入沿用项目现有审批规则。需要写入长期记忆的发展判断由用户确认。阅读时长、翻页进度和练习表现分别展示，掌握程度需要结合具体产出判断。

## 2. 目标用户与场景

| 用户 | 场景 | 期望结果 |
| --- | --- | --- |
| 自主学习者 | 阅读一本知识类书籍 | 理解章节内容与核心概念 |
| 学生 | 结合教材和课堂笔记复习 | 整理重点、完成练习 |
| 专业人士 | 阅读专业报告、技术资料 | 快速定位信息、理解结论 |
| 研究人员 | 同时阅读多份资料 | 对照观点并追溯来源 |

首个验证场景建议聚焦自主学习者阅读一本书。首版文件格式暂按 PDF 和粘贴文本考虑，是否优先支持 EPUB 需结合目标书籍样本评估。

## 3. 核心流程

创建学习空间 → 添加资料 → 查看概览 → 提问与追问 → 查看原文引用 → 保存笔记或生成学习材料 → 再次进入继续学习。

以学习一本书为例，用户上传书籍后先查看概览，再针对一章提问；遇到难懂的段落时请求解释，点击引用回到原文；结束时保存笔记，按需完成理解题；下次进入恢复已有资料、对话与阅读位置。

异常分支包括上传失败、资料解析失败、回答生成失败，以及资料不足以回答问题。

## 4. 信息架构与页面

### 4.1 学习空间列表

建议从广莫的学习页进入。空间列表支持创建、打开、重命名和删除。

每个卡片展示名称、资料数量、最近更新时间，以及可选的关联学习目标。首次使用时突出创建入口，说明可以添加哪些资料。

### 4.2 学习工作台

桌面端采用三栏候选布局，具体布局在原型阶段验证。

| 区域 | 内容 | 主要操作 |
| --- | --- | --- |
| 左侧来源区 | 添加资料入口、资料列表、选择状态 | 上传、勾选、打开、移除资料 |
| 中间对话区 | 资料概览、推荐问题、对话记录、输入框 | 提问、追问、查看引用、保存回答 |
| 右侧学习材料区 | 笔记、学习指南、练习题、记忆卡，及后续评估的图文、音视频等产物 | 创建、查看、使用学习材料，按类型管理产物 |

点击来源或回答引用时打开原文查看区域，保留当前对话位置。窄屏下可通过来源、对话、学习材料三个视图切换，保留各视图的操作状态。

### 4.3 书籍伴读扩展

围绕一本书的学习可进一步评估原文与 AI 对话双栏布局。用户划选段落后使用“解释一下”“举个例子”“问 AI”，输入框上方展示可移除的选段卡片；点击引用时在原文中定位并高亮。

章节导航、划选提问、章节理解检查属于书籍伴读的后续评估项。若首版确定采用该布局，需要验证长篇阅读时的原文展示与对话切换体验。

该部分的具体交互与验收补充在第 14 节。

## 5. 功能需求

以下要求用于功能进入开发后的设计与验收评估。

### F01 创建与管理学习空间

**用户故事**

作为学习者，我希望为一本书建立独立空间，以便集中保存资料、问题和学习成果。

**交互要求**

- 点击创建后进入工作台，展示添加资料入口。
- 用户可以修改空间名称，并按需关联已有学习目标或项目。
- 列表按最近更新时间排序。
- 删除前明确提示删除范围，用户确认后执行。

**验收标准**

刷新或重新登录后，空间及其内容仍可访问。删除操作完成后，列表与详情状态一致；关联的学习目标保留，失效的资料入口得到明确标记。

### F02 添加与解析资料

**用户故事**

作为学习者，我希望上传资料后即可围绕内容提问。

**首版候选范围**

支持 PDF 和粘贴文本，其他格式在后续评估中确定。

**交互要求**

- 支持文件选择和拖拽上传。
- 每份资料分别显示“上传中”“解析中”“可使用”“失败”。
- 失败时显示原因与重试入口。
- 有可用且已选中的资料后允许开始提问。
- 重复上传时提醒用户确认是否继续。
- 文件格式、大小及文本量限制在上传前可见，具体上限待评估。

**验收标准**

可用资料能够打开并展示正文。失败资料不会作为问答依据，重试不会产生意外的重复来源。扫描件、加密文件、复杂排版的支持情况在样本验证后明确，并在上传反馈中说明。

### F03 选择问答来源

**用户故事**

作为学习者，我希望指定 AI 使用哪些资料，控制回答范围。

**交互要求**

- 每份资料具有勾选状态。
- 新增资料解析成功后默认勾选。
- 输入框附近显示当前选中的资料数量。
- 未勾选任何资料时提示用户选择来源。
- 每次提交问题时固定当次来源范围，后续改选应用于下一次提问。

**验收标准**

回答的资料依据与引用来自当次选中的来源，用户能识别提问范围。来源变化后的回答重新核对依据，历史对话中的旧资料结论需要重新验证后才能使用。

### F04 自动概览与推荐问题

**用户故事**

作为首次打开资料的用户，我希望迅速知道它的主题，并找到合适的问题入口。

**交互要求**

- 资料就绪后展示简短概览。
- 提供少量基于资料内容的推荐问题。
- 点击推荐问题即可提交。
- 来源变化后允许更新概览与推荐问题，并标明已有概览对应的来源范围。

**验收标准**

概览反映所选资料的主要内容。生成失败时，用户仍能直接提问。

### F05 AI 问答与追问

**用户故事**

作为学习者，我希望通过连续对话理解资料中的内容。

**支持的问题类型**

- 总结某一章的主要观点。
- 解释概念和段落。
- 比较资料中的不同观点。
- 说明论证过程。
- 根据资料举例帮助理解。

**交互要求**

- 提交后立即显示问题与生成状态。
- 回答逐步显示，允许停止生成。
- 失败时保留用户问题并允许重试。
- 连续追问保留必要的对话上下文，并遵循当次来源选择。
- 资料不足时明确说明缺少什么依据。
- 用于教学的补充例子标明为 AI 补充示例，与原文内容清晰区分。

**验收标准**

用户可完成连续追问。重试不会重复插入用户消息，生成中切换页面不会导致已完成记录丢失。用户停止或发生中断后，已有回答标记为未完成。

### F06 引用与原文定位

**用户故事**

作为学习者，我希望检查答案的依据，并回到相关原文继续阅读。

**交互要求**

- 回答中的关键资料性陈述附带引用。
- 点击引用打开对应来源，定位并高亮相关片段。
- 用户查看原文后可以继续原有对话。
- 来源失效时显示明确提示。

**验收标准**

引用准确关联对应资料和片段。页码等定位信息以实际解析结果为准，引用标记能对应到实际内容。回答内容与引用依据的一致性纳入质量评估。

### F07 保存笔记

**用户故事**

作为学习者，我希望保留有价值的回答，并加入自己的理解。

**交互要求**

- 回答提供“保存到笔记”操作。
- 用户可新建和编辑自己的笔记。
- 保存的 AI 回答保留来源信息。
- 笔记编辑后显示保存状态，失败时保留编辑内容并允许重试。

**验收标准**

重新进入学习空间后，笔记内容完整，仍有效的引用可以访问。笔记与广莫现有笔记数据的复用关系在实现评估中确认。

### F08 生成学习材料

**用户故事**

作为学习者，我希望从同一份资料生成适合整理和复习的内容。

| 类型 | 输入 | 输出 | 交互 |
| --- | --- | --- | --- |
| 学习指南 | 所选资料、学习主题 | 章节重点与概念说明 | 生成后阅读与保存 |
| 练习题 | 所选资料、难度、题量 | 题目、答案与解释 | 作答后查看反馈 |
| 记忆卡 | 所选资料、主题 | 正面问题、背面答案 | 翻面查看、继续下一张 |

**交互要求**

- 明确展示生成所用的来源。
- 生成任务显示处理中、完成或失败状态。
- 已生成内容保存在当前学习空间。
- 失败后允许重试，并保留生成配置。
- 理解题反馈提供相关原文依据，并允许用户指出反馈有误。

**验收标准**

材料围绕所选资料生成，用户能够再次打开使用。具体内容长度、题量与生成限制在实现阶段确定。生成过程发生中断或重复重试时，产物状态与实际结果一致。

## 6. 关键状态与异常处理

| 情况 | 产品行为 |
| --- | --- |
| 空间没有资料 | 展示添加资料入口 |
| 资料正在解析 | 显示处理状态，待就绪后开放使用 |
| 文件无法解析 | 解释失败原因，提供重新上传入口 |
| 没有选中来源 | 提示选择资料 |
| 来源不足以回答 | 说明依据不足，建议更具体地提问或补充资料 |
| 回答生成中断 | 保留已生成内容并标记未完成，允许重试 |
| 引用来源已被删除 | 保留历史回答，标记原文不可访问 |
| 学习材料生成失败 | 显示失败状态，保留生成配置供重试 |
| 页面重新打开 | 恢复已保存的资料、对话及阅读位置，展示任务实际状态 |

## 7. 数据与权限要求

- 学习空间、来源、对话、笔记和生成材料关联到所属用户。
- 用户只能访问有权限的内容，默认采用私人学习空间。
- 用户提交问题时记录当次来源范围，便于追溯回答依据。
- 学习材料记录生成时的来源范围，资料变化后展示历史生成依据。
- 删除来源后明确标记受影响的历史引用；删除整个空间时处理所属资料、对话和生成内容。
- 上传文件、解析文本和检索索引的保留与清理策略在实现评估中统一确认。
- 关联项目、学习目标和长期记忆沿用广莫现有的数据与用户确认规则。

首版建议先完成个人使用，共享和协作放入后续评估。

## 9. 效果指标

| 指标 | 定义 | 用途 |
| --- | --- | --- |
| 资料导入成功率 | 成功解析次数 ÷ 上传次数 | 判断用户能否顺利开始 |
| 首次问答完成率 | 获得首条完整回答的新用户 ÷ 创建学习空间的新用户 | 判断初次体验是否顺畅 |
| 有效回答率 | 抽样评估中正确且有来源支持的回答占比 | 判断回答质量 |
| 引用定位成功率 | 正确打开对应原文片段的引用占比 | 判断追溯功能是否可靠 |
| 持续学习率 | 首次使用后一定时间内再次使用同一空间的用户占比 | 判断持续价值 |
| 理解检查表现 | 用户在相关练习中的表现变化 | 探索对学习效果的帮助 |

具体目标值、统计窗口与评估样本在试用前确认。练习表现需结合题目难度、原文内容和用户反馈解释。

## 10. 开发前待确认事项

| 事项 | 需要得到的结论 |
| --- | --- |
| 目标用户与首个场景 | 优先支持知识类书籍、教材还是专业资料 |
| 学习模块入口 | 学习空间与现有学习目标、任务、项目的关联方式 |
| 首版文件格式 | 根据样本决定 PDF、文本和 EPUB 的优先级及支持范围 |
| 阅读交互 | 在原型中验证三栏工作台与原文／对话双栏的适用场景 |
| 长文与图表处理 | 验证跨章节问题、表格、图示和扫描件的解析与回答效果 |
| 原文定位 | 确认稳定的页码或段落定位方式及引用质量验收样本 |
| 数据复用 | 确认现有资料、笔记、对话和学习任务表示的复用方式 |
| 生成体验与成本 | 通过代表性样本确认响应时间、生成限制和运行成本 |
| 任务恢复 | 明确上传、解析、生成的中断、重复提交与重试处理 |
| 开发排期 | 在需求评估与原型验证后确定范围、负责人和时间 |

后续评估可沿用项目已规划的 Web、模型接入、资料处理、检索与引用、数据持久化及异步任务能力，具体采用情况以技术文档和实现证据为准。

## 13. 扩展功能需求

每项先记录官方可确认的功能，再给出广莫的候选交互与验收要求。以下“候选交互”和“验收”均为本项目拟议设计。

### F09 多类型资料导入

**参考功能**

官方列出的来源包含 PDF、EPUB、Word、文本、Markdown、CSV、PowerPoint、图片、音频、Google Docs／Slides／Sheets、网页、YouTube、笔记、符合条件的 Play Books 电子书与教材，以及 Gemini 对话。网页按文本导入，YouTube 依赖公开视频字幕，音频转录为文本。[来源说明](https://support.google.com/gemininotebook/answer/16215270?co=GENIE.Platform%3DDesktop&hl=en)

**候选交互**

- “添加资料”按本地文件、粘贴文本、链接和已连接服务展示入口，每种入口说明支持范围。
- 批量导入时逐项显示解析状态，允许重试失败项；成功项可先使用。
- 导入结果展示实际提取的正文、图片或转录，方便检查缺失。
- 电子书与教材目录入口先检查用户可访问的内容，接入渠道与授权方式单独评估。
- 保存来源类型、标题、原始地址及导入时间，便于后续定位和更新。

**验收**

各类来源使用代表性样本验收。用户能确认实际导入内容；不可用链接、无字幕视频、无法识别的文件返回逐项原因。部分成功时，成功项数量、失败项和可重试范围准确对应。

### F10 来源组织与更新

**参考功能**

来源支持自动分类和手动标签调整。Drive 来源支持自动与手动同步，原文件访问权变化会影响来源可用性。已有产物保留生成时的内容。[来源说明](https://support.google.com/gemininotebook/answer/16215270?co=GENIE.Platform%3DDesktop&hl=en)

**候选交互**

- 来源列表支持标签新增、修改、删除与移动来源，自动分类结果可修正。
- 展示最近同步时间、更新中、更新失败和访问失效状态。
- 更新完成后，后续回答使用新版本；历史引用保留版本标记，必要时提示原文已变化。
- 生成材料显示“基于较早版本”，用户可选择重新生成。

**验收**

标签修改保留原资料；同步失败后仍能明确识别已保存版本。权限失效的外部来源停止参与新问答。更新期间的提问绑定确定的资料版本，历史引用可解释其生成依据。

### F11 快速搜索与深度研究

**参考功能**

Fast Research 可搜索 Web 或 Drive，用户选择结果加入来源；Deep Research 生成研究报告及来源列表，供用户选择导入。[研究说明](https://support.google.com/gemininotebook/answer/16215270?co=GENIE.Platform%3DDesktop&hl=en)

**候选交互**

- 在来源区输入研究问题，选择搜索范围与快速搜索／深度研究。
- 结果列表显示标题、简介、原始链接和导入状态。
- 深度研究展示运行状态，用户可继续其他操作并在完成后回看结果。
- 用户选择要加入的报告和来源，再进入解析流程。
- 支持取消、失败重试及部分导入，已导入项目提供重复提示。

**验收**

研究结果与已选入学习空间的来源明确区分。取消后停止后续导入；配额或解析失败时，用户能查看成功与失败的项目，重试保持结果一致。

### F12 聊天配置与扩展动作

**参考功能**

聊天支持默认、学习引导及自定义风格、回复长度、历史清理。官方还列出实验性的网页研究、代码执行、文件与图表生成和产物版本修改能力。[聊天说明](https://support.google.com/gemininotebook/answer/16179559?hl=en)

**候选交互**

- 聊天设置提供解释深度、回答长度和自定义要求，保存后应用于后续回答。
- 历史清理前展示影响范围；清理对话和删除已保存笔记分别操作。
- 如引入扩展动作，在回答前展示使用的资料范围与拟调用工具，运行中显示进度及停止入口。
- 资料问答与联网研究分别标识依据；生成文件提供预览、下载和版本信息。
- 涉及外部写入时，沿用广莫已有审批规则。

**验收**

修改配置后能验证输出差异。停止、重试和恢复不会重复执行外部动作。生成文件可打开，版本修改与原文件的关系可追踪，工具失败有明确状态。

### F13 笔记作为资料与导出

**参考功能**

笔记可以作为问答和生成材料的来源，历史 Studio 笔记可转换为来源，并支持导出到 Google Docs。移动端笔记编辑有功能限制。[笔记说明](https://support.google.com/gemininotebook/answer/16262519?hl=en)

**候选交互**

- 保存回答或创建笔记后，提供“用于后续问答”选项，并显示作者来源。
- 允许将历史笔记批量加入来源，保留与原始笔记的关联。
- 修改带引用的内容时检查引用对应关系，提示用户核对已改写段落。
- 导出前选择格式或目标服务，完成后提供文件或目标链接。

**验收**

笔记能按选中状态参与问答。AI 摘录与用户笔记在引用中可辨认，避免同一 AI 结论循环引用形成独立证据的假象。导出失败保留原笔记，导出内容与操作时的版本一致。

### F14 思维导图

**参考功能**

可从来源生成主题分支图，展开或收起节点、缩放，点击节点进入相关对话，并下载或通过笔记本共享。官方目前标注移动应用支持受限。[思维导图说明](https://support.google.com/gemininotebook/answer/16212283?hl=en)

**候选交互**

用户选择资料后生成导图，点击节点在对话中带入节点主题与来源范围。支持全屏、分支折叠、重新生成和下载，返回时保留阅读位置。

**验收**

节点文本可读，分支展开和缩放可用。节点追问限定正确来源；重新生成前能保留旧版本，导出结果与所选版本一致。

### F15 音频概览与交互式收听

**参考功能**

音频概览提供深入讨论、简报、评论和辩论等形式，可设置语言、长度与重点。支持后台播放、倍速、下载和共享；交互模式允许语音加入讨论，官方注明该模式目前限英语。[音频说明](https://support.google.com/gemininotebook/answer/16212820?hl=en)

**候选交互**

- 配置资料、形式、语言和关注点后开始后台生成。
- 播放器支持暂停、进度调整、倍速和返回工作台继续听。
- 交互模式明确麦克风状态，用户提问后播放回复，再返回原音频。
- 分别显示普通收听与语音互动的可用范围，下载和共享使用产物权限。

**验收**

离开页面再返回能看到真实任务状态；播放、暂停及恢复位置准确。语音权限被拒绝后可继续普通收听。互动内容的保存规则在开启前说明。

### F16 视频概览与生成前共创

**参考功能**

视频概览支持形式、语言、视觉风格和重点设置、播放与下载。部分套餐可先审阅制作说明再渲染；电影化形式、语言、年龄和套餐条件存在差异。[视频说明](https://support.google.com/gemininotebook/answer/16454555?hl=en)

**候选交互**

- 选择资料和输出配置，展示预计处理状态与生成入口。
- 如采用共创流程，先生成制作说明，用户集中修改并确认后进入渲染。
- 支持立即生成或稍后生成，任务状态区分排队、待审阅、渲染中和完成。
- 成品可全屏播放、拖动进度、调整倍速、下载或共享。

**验收**

较长任务可离开后恢复查看。用户确认的制作说明与渲染版本一致；失败时保留配置和已确认说明。画面、文字、解说与资料的对应关系通过样本评估。

### F17 报告与交互式学习概览

**参考功能**

报告支持文档形式和嵌入学习产物的交互形式，可选择模板、修改生成要求并分享；交互式报告的部分能力有 Web 和年龄限制。[报告说明](https://support.google.com/gemininotebook/answer/18323649?hl=en)

**候选交互**

- 将 F08 的学习指南扩展为报告入口，提供 FAQ、摘要、学习指南和自定义报告。
- 交互式报告中可选择添加推荐产物，分别显示嵌入产物的生成状态。
- 文档报告支持复制与导出，交互式报告提供在线查看和分享。
- 引用保持可访问，来源变动后提示生成依据的版本。

**验收**

报告正文可独立阅读。嵌入产物失败有单独的重试入口，其他内容继续可用。导出时明确交互内容的呈现方式，避免无提示丢失材料。

### F18 数据表与结构化导出

**参考功能**

Studio 支持按语言和行列要求生成数据表并导出到 Sheets，导出包含引用信息。[工作台说明](https://support.google.com/gemininotebook/answer/16206563?hl=en)

**候选交互**

用户描述需要比较的对象与字段，系统生成表格并提供来源引用。表格支持预览、修改生成要求、重新生成以及 CSV 或表格服务导出，具体格式在选型时确定。

**验收**

无法从资料确定的值明确留空或标记缺失。数字、单位、日期和来源可核对，导出保留列结构与引用关联。

### F19 记忆卡与测验的学习过程

**参考功能**

支持难度和主题定制、解释与提示、进度保存、结果回顾和再次练习。记忆卡还支持掌握标记、打乱、删除、只练错卡和 CSV 下载。[记忆卡与测验说明](https://support.google.com/gemininotebook/answer/16958963?hl=en)

**候选交互**

- 卡片正面显示问题，翻面显示答案，允许标记“已理解”或“还需复习”。
- 测验逐题作答，可请求提示；提交后展示解释和依据。
- 结束后显示本次结果，提供重做全部和针对困难内容再练入口。
- 保存会话进度，允许重新开始；删除卡片后同步更新本组数量。

**验收**

重新进入后恢复到正确位置，个人作答记录与共享题目内容分别保存。答案显示时机、错题筛选与统计一致。学习标记可更正，CSV 导出包含完整的题目和答案字段。

### F20 信息图

**参考功能**

可设置语言、详略、方向、视觉风格和提示词，生成单张视觉摘要，并支持缩放、PNG 下载、重命名及分享。官方列出年龄与平台条件。[信息图说明](https://support.google.com/gemininotebook/answer/16758265?hl=en)

**候选交互**

配置面板预览横向、纵向或方形规格，用户确定重点后后台生成。成品提供放大检查文字、查看生成要求、重新生成和下载入口。

**验收**

文字可辨认，图中数字和关系与资料一致。导出保留指定方向和内容，生成失败保留配置，修订结果形成可识别的新版本。

### F21 幻灯片生成与修订

**参考功能**

支持配置资料、形式、语言和长度，生成后播放、导出 PDF／PPTX，并按页提交修订、删除或排序。部分套餐支持生成前审阅大纲；官方说明当前修订阶段存在来源使用限制。[幻灯片说明](https://support.google.com/gemininotebook/answer/16757456?hl=en)

**候选交互**

- 选择资料和讲解对象，填写重点；可先审阅大纲再生成。
- 成品显示缩略图、全屏演示、逐页修改说明、待应用更改和版本列表。
- 允许撤销待删除页面和调整顺序，确认后生成修订版。
- 导出前明确文件格式及内容可编辑范围。

**验收**

修订与排序应用于正确页面，失败保留旧版本和修改要求。导出文件能打开且顺序正确。广莫若采用此功能，事实性修订需要重新核对来源。

### F22 共享、复制、公开内容与统计

**参考功能**

官方提供查看者／编辑者共享、公开空间与产物链接、允许复制开关及使用统计。Chat View 隐藏部分界面，但查看者仍可能访问来源与产物。[空间管理说明](https://support.google.com/gemininotebook/answer/16206563?hl=en)

公开与精选笔记本支持发现和访问共享内容，账号类型和移动端入口有差异。[公开与精选说明](https://support.google.com/gemininotebook/answer/16322204?hl=en)

**候选交互**

- 私人空间由所有者选择成员和角色，展示各角色的实际访问范围。
- 公开分享前预览可见内容，分享后可撤销链接和成员权限。
- “仅对话”如需限制原文访问，应设计独立的数据权限并验证。
- 复制时展示将复制的资料和产物范围，个人聊天、笔记和作答记录分别处理。
- 公共内容入口提供主题、简介、作者和打开操作；用户可举报问题内容。
- 统计展示访问与提问趋势及统计时间范围，权限以空间所有权或管理权确定。

**验收**

使用不同角色和匿名访问验证资料、产物与操作权限。撤销后旧链接失效，复制产生独立空间且边界明确。多人使用时，个人聊天和作答记录按各自权限隔离。

### F23 产物管理与完成通知

**参考功能**

官方工作台支持多种产物，并提供生成要求查看、完成通知和未读标记。[工作台说明](https://support.google.com/gemininotebook/answer/16206563?hl=en)

**候选交互**

- 产物列表统一显示类型、名称、状态、来源版本和生成时间。
- 支持打开、重命名、查看生成配置、重新生成、下载和删除，各类型按实际能力显示操作。
- 页面离开后任务继续时，在重新进入后同步实际状态。
- 用户主动开启浏览器通知，通知点击后进入对应产物；拒绝通知权限时保留站内未读提示。

**验收**

相同任务状态一致，完成通知只触发一次。删除和重新生成作用于指定产物，已打开状态可跨会话保持，导出目标与展示版本一致。

### F24 移动端与语音学习

**参考功能**

移动端支持系统分享导入、音频后台与离线收听，部分创建和设置能力少于 Web。离线音频与导出设备文件的能力不同。[移动端说明](https://support.google.com/gemininotebook/answer/16296687?hl=en)

资料语音对话支持打断、麦克风控制和转录查看，官方限定移动端及年龄条件。[聊天说明](https://support.google.com/gemininotebook/answer/16179559?hl=en)

**候选交互**

- 系统分享面板接收资料后选择目标空间并显示导入结果。
- 语音会话显示录音、思考、播报状态，支持中断和切回文字。
- 音频提供离线保存、下载进度、空间占用和删除缓存。
- 多端恢复资料、对话和学习进度；离线时展示可用内容及同步状态。
- 若采用录音转资料，分别确认原始录音与转录文本的保存方式。

**验收**

拒绝麦克风权限、断网和存储不足时有明确反馈。恢复网络后进度正确合并；系统分享重复提交不会意外新增多份资料。Web 与移动端维护独立的能力清单。

### F25 跨应用使用与连接服务

**参考功能**

Gemini Apps 可使用笔记本上下文并同步部分信息；Google Search AI Mode 也可使用笔记本，存在语言和地区限制。独立的 Connected apps 功能提供应用能力说明、聊天调用与笔记本内开关。[Gemini 集成说明](https://support.google.com/gemininotebook/answer/17003757?hl=en) · [Search 集成说明](https://support.google.com/gemininotebook/answer/17513891?hl=en) · [连接应用说明](https://support.google.com/gemininotebook/answer/18784282?hl=en)

**候选交互**

- 在广莫主对话和项目中选择学习空间作为上下文，并展示当前使用范围。
- 从学习对话回到资料工作台时，保留来源定位和已有学习记录。
- 连接服务前展示读取范围及支持动作，按空间配置是否使用。
- 用户可断开服务；连接失效时提供重新连接或移除入口。
- 跨系统导出和回写分别说明同步方式与冲突处理。

**验收**

跨入口调用继承资料权限，连接撤销后停止新访问；写入操作与用户批准的目标一致。参考产品的 Google 生态入口记录为对照项，广莫的具体连接对象另行选型。

### F26 设置、账号、额度与反馈

**参考功能**

官方提供不同套餐的功能额度与升级入口，工作或学校账号有管理条件。[套餐说明](https://support.google.com/gemininotebook/answer/16213268?hl=en) · [额度管理](https://support.google.com/gemininotebook/answer/17670842?hl=en)

支持主题、输出语言、内容评价和问题反馈。[主题设置](https://support.google.com/gemininotebook/answer/16225229?hl=en) · [语言设置](https://support.google.com/gemininotebook/answer/16261963?hl=en) · [反馈说明](https://support.google.com/gemininotebook/answer/16179536?hl=en)

**候选交互**

- 登录后展示账号可使用的功能。不可用入口说明账号、地区、组织配置或额度原因。
- 在生成前展示所需额度，达到上限后保留配置并说明恢复条件。
- 套餐和定价由广莫另行评估，配额应可配置。
- 设置中支持主题、默认输出语言和通知；单次生成可覆盖默认语言。
- 回答和产物提供反馈入口，发送前展示将附带的内容，用户可确认提交。
- 帮助入口覆盖使用说明、常见问题和支持渠道；公开内容支持举报。

**验收**

不可用功能与实际账号状态一致。重复请求、失败与取消的额度处理可解释；偏好跨会话保存，反馈附带内容与用户确认范围一致。

## 14. 广莫书籍学习补充方案

以下需求来自本次产品讨论，作为广莫的自主设计单独记录。它们与参考产品功能分开评估。

### G01 学习目的与章节导读

用户导入书籍后可选择“快速了解”“逐章读懂”或“解决一个问题”，已有学习目标可直接关联。选择逐章读懂时展示识别出的目录并允许确认；目录缺失时提供按页码或内容片段选择范围的方式。

学习目的可随时修改，影响后续导读与推荐问题。章节开始时展示核心问题、关键概念和一个引导问题，用户点击开始阅读进入原文。

**验收**

用户可以跳过目标设置直接阅读。章节范围与原文对应；修改目的保留已有笔记和进度，并更新后续引导。

### G02 原文阅读与划选提问

原文与 AI 对话并排展示，目录可展开和收起。划选文字后显示“解释一下”“举个例子”“问 AI”，输入框上方显示当前选段、章节和移除入口。

提交问题时记录选段及来源版本；切换章节后清除待提交的旧选段并更新输入提示。回答引用可跳回原文并高亮；用户返回时保留对话和阅读位置。

**验收**

跨页选取、取消选取、换章和删除来源后，提问范围符合界面提示。再次打开恢复正确位置；缩放或重新排版后仍能定位已保存的原文片段。

### G03 章节理解检查与复述反馈

用户点击“读完这章”后可选择回顾、做题或用自己的话复述。检查每次呈现一道问题，提交后给出反馈、遗漏的概念和原文依据。

用户可跳过、修正 AI 反馈或请求解释。遇到困难时，提供回看段落、换例子解释和再试一道题的入口；完成后可继续下一章。反馈分别保存用户回答、AI 建议和用户修正。

**验收**

提交前的题目视图保持答案隐藏。反馈关联当前章节和实际回答；阅读完成、练习完成与理解表现分别保存。返回或重试不会丢失已提交回答。

### G04 复习安排与每周回看

依据用户选择的困难概念和练习反馈提出复习任务草稿，展示材料、预计时长、预期产出和建议时间。用户可确认、修改、跳过、改期或暂停，沿用广莫现有学习安排交互。

每周回看可汇总用户确认的学习成果、尚存问题和后续建议，保留原文或练习依据。重要判断写入长期记忆时沿用用户确认机制。

**验收**

复习草稿经确认后进入学习安排，重复生成时识别已有任务。暂停后停止后续安排，外部日历动作遵循现有审批规则。
