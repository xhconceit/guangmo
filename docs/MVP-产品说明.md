# 广莫 MVP 产品说明

> 广莫是一个个人 Agent。它先帮助用户管理、理解与推进真实生活；再用“自由而全面的发展”作为所有判断与行动的长期方向。

## 1. MVP 要验证什么

不验证 AI 能否完成任务，而验证：

> 当 Agent 同时拥有用户的日程、任务、项目、笔记与长期方向时，能否比普通个人助手更好地判断什么值得做，并将判断推进为真实行动？

成功不是完成更多任务，而是用户说：“它让我看清了真正重要的事，也让我开始了那件事。”

## 2. 目标用户

- 有多个并行的工作、兴趣或个人项目；
- 已使用日历、笔记或任务工具，但仍感到生活被外部要求牵着走；
- 有长期想发展却常被日常事务挤掉的方向；
- 愿意授权 Agent 读取有限的个人上下文。

## 3. MVP 产品承诺

> 广莫每天帮你把事情推进；每周帮你判断，你正在把时间交给什么。

它具备五项基础能力：

1. 记忆：保存用户确认的重要信息；
2. 组织：汇总日程、任务、笔记与项目；
3. 研究：围绕问题查找、解释与整理信息；
4. 执行：起草、规划、提醒与跟进；对外动作必须经用户确认；
5. 判断：结合用户的发展方向，识别值得保留、停止或开始的行动。

第五项是广莫的差异，不是独立功能。

## 4. 核心概念

### 个人上下文

用户授权广莫读取或手动记录：

- 日历事件；
- 任务与项目；
- 笔记、收藏与学习材料；
- 用户确认的长期方向、重要关系与现实限制。

MVP 不接入邮件、社交媒体、健康数据，也不在未经确认时自动抓取私人信息。

### 发展方向

由用户定义并随时修改的长期方向，例如建立独立创作能力、理解 AI 对行业的影响、留出亲密关系时间或稳定身体状态。

这不是 KPI，也不是 Agent 对用户下达的目标。

### 发展判断

Agent 在规划、学习建议和任务排序时额外提出：

- 这项行动与用户确认的发展方向有什么关系？
- 它扩大什么能力或选择？
- 它会挤掉什么？
- 是否值得现在投入？

Agent 必须区分事实、推测与用户确认的判断。

## 5. 第一个用户闭环

### 周一：捕捉

用户打开广莫，看见今日承诺、正在推进的项目，以及一项被长期搁置的方向。

用户说：“我今天很忙，但我不想又把摄影放掉。”

广莫读取用户已授权的日程和摄影项目，提出可修改的选择：

- 周三晚间预留 45 分钟，准备周末拍摄；
- 本周不安排拍摄，但移除一个低价值会议，为下周留出完整上午。

用户选择、修改或拒绝。

### 日常：推进

广莫围绕用户确认的方向工作：

- 将“想理解 AI”整理为研究问题；
- 为创作项目搜集资料、列出下一步；
- 根据日程起草现实可行的计划；
- 准备邮件、文档、会议提纲或学习材料。

发送邮件、创建约会、购买、提交表单等对外动作，均需用户最后确认。

### 周末：回看

广莫生成一份三分钟以内的回看：

- 本周推进了什么；
- 哪些行动扩展了选择；
- 什么在持续消耗；
- 一项保留、一项停止、一项开始的建议。

用户可接受、修改、忽略，或要求广莫更改判断方式。

## 6. MVP 界面

### 首页：今天

- 今日承诺与日程；
- 正在进行的项目；
- 一项来自发展方向的建议；
- 对话入口。

### 发展页

- 用户确认的长期方向；
- 关联项目、学习、关系与行动；
- Agent 推测必须标为“观察”；
- 用户可编辑或删除任何一项。

### 项目 / 发展线页

将一个真实问题变成一条路径：

问题 → 想理解或改变什么 → 研究、学习与实践 → 作品、判断或新能力 → 下一次选择。

### 每周回看页

- 本周发生什么；
- 哪些行动与发展方向有关；
- 保留、停止、开始三项建议；
- 用户反馈与修正入口。

## 7. Agent 行为规则

### 可以主动做

- 汇总用户已授权的信息；
- 发现项目停滞、承诺冲突、长期方向长期未获投入；
- 主动提出建议、研究、草稿与计划；
- 准备可供用户审批的外部动作；
- 按用户设定的频率提供简报或回看。

### 必须询问

- 新增、修改或删除日历事件；
- 发送消息、邮件或任何对外内容；
- 购买、预约、提交表单；
- 接入新数据源；
- 将推测写入长期记忆或发展方向。

### 绝不做

- 为用户指定人生目标；
- 将低效、情绪或停滞视为必须优化的问题；
- 用隐性指标评价用户是否发展得更好；
- 未经同意读取、共享或训练用户私人数据。

## 8. 技术范围

MVP 只有四类基础能力：

| 类别 | MVP 范围 |
|---|---|
| 对话与 Agent | 长对话、工具调用、任务规划、可中断执行 |
| 用户记忆 | 用户可见、可编辑的结构化记忆 |
| 日程与任务 | 一个日历连接器 + 手动任务 / 项目输入 |
| 研究与写作 | 网页研究、笔记整理、文档草拟 |

不做复杂多 Agent 系统、不做全量人生数据接入、不做无人审批的自动对外执行。

## 9. MVP 不做什么

- 课程市场；
- 心理治疗或诊断；
- 社交网络；
- 量化自我仪表盘；
- 无人审批自动化；
- 全知全能的人生教练。

## 10. 下一步

依据技术方案初始化 TypeScript Monorepo，先实现手动项目输入、可编辑记忆、对话和每周回看草稿。日历连接器、自动化和长期记忆在基础闭环稳定后再加入。
