# 广莫设计规范

## 1. 产品气质

广莫是帮助用户管理生活，安排学习和推进长期方向的个人 Agent。

界面应平静，清晰，有留白，让用户容易看见当前重要的事情。
避免制造紧迫感，不使用排行榜，连续打卡或惩罚性提醒。

用户始终可以修改，拒绝或暂停 Agent 的建议。

## 2. 图标

### 风格

图标统一用 Lucide。原型使用官方 0.468.0 版本 SVG，来源与许可证保存在 `prototype/vendor/lucide/`，内嵌使用以支持离线访问。

图标保持圆端点与圆连接；导航图标 20px、默认描边 1.7px，选中时 2px 并使用局部浅填充；普通工具图标 18px、描边 1.5px，下拉箭头 12px。保持现有 44px 点击范围与 32px 选中底块。

### 品牌图标

广莫 Logo 使用正式 SVG，不以图标库中的图标替代。

## 通用交互

### 输入框

### 输入法与键盘

聊天输入框：
- 中文输入法组词期间，Enter 仅确认候选词，不发送。
- 非组词状态下，Enter 发送，Shift + Enter 换行。
- 空白内容不发送。

多行编辑器：
- Enter 默认换行，不提交。


## 视觉基调

- 采用现代、简洁的工作台风格，保留柔和圆角与充足留白。
- 当前原型使用浅色银灰：白色主区、浅灰侧栏、深灰正文与灰色辅助文字。
- 主要操作使用黑色按钮；选中态使用浅银灰背景，焦点使用清晰的灰色轮廓。
- 所有区域统一使用系统无衬线字体，不使用宋体、水墨晕染或仿纸纹理。
- 减少独立卡片和背景块，用间距与轻量分隔建立层次。

### 布局与入口

- 默认图标窄栏宽 56px，可展开为 184px 完整侧栏。侧栏仅保留功能入口、连接器与账户。
- 新建对话和历史对话位于对话页顶部，不出现在侧栏。
- 主区域白色，侧栏浅银灰，外层背景略深；选中项用轻量浅灰底，不加投影。
- 侧栏与主区分离，均使用 16px 圆角，桌面外距与面板间距统一 6px。
- 对话区最大宽度 736px，内容页最大宽度 880px；桌面内容左右内边距 32px。
- 顶部栏高度 64px；对话记录独立滚动，输入区留在底部。

### 间距与留白

使用 4px 基础尺度。组件内部与区域之间根据层级选用以下值，不随意添加相近数值。

| 尺度 | 用途 |
|---|---|
| 4px | 侧栏导航项间距、紧密关联控件 |
| 8px | 图标与文字、相邻操作 |
| 12px | 常规按钮内边距、常规容器内边距、文字组间距 |
| 16px | 表单与面板常规内边距、相邻内容组 |
| 24px | 输入框顶部内边距、内容面板内边距、区块间距 |
| 32px | 标题与输入区之间、消息组之间、主区内边距 |
| 48px | 大区块之间的留白，按需使用 |
| 64px | 开始页整体位置的视觉平衡留白 |

- 同一组件内部使用同一尺度；密切相关内容距离小，不同分组距离大。
- 图标栏中交互区域为 44 × 44px，项间距 4px，上下分组间距 12px；窄栏左右各留 6px。选中与悬停底块为 32 × 32px、圆角 10px，点击区域仍为 44 × 44px。
- 面板外距 6px 为独立布局值，不用于组件内部。
- 间距通过 CSS 的 `--space-*` 变量引用；布局使用 `--frame-gap`、`--page-inset`、`--header-height` 等语义变量。

### 圆角

| 类型 | 圆角 |
|---|---|
| 小按钮、工具入口 | 12px |
| 导航选中态、外层面板、常规浮层 | 16px |
| 输入框、消息气泡、内容分组 | 24px |
| 发送按钮、头像 | 圆形 |
| 快捷文字入口 | 胶囊形，仅悬停显示背景 |

### 文字与层级

- 系统无衬线字体；主标题 30px，内容页标题 28px，区块标题 18–20px。
- 正文 14–15px；导航 13px；辅助文字 11–12px。
- 主要文字深灰，次要文字中灰，辅助文字浅灰。黑色主按钮是最强操作强调。
- 内容分组使用低对比度浅灰背景，不堆叠嵌套面板；浮层使用白底和轻微投影，不使用黑色边框。

### 响应式

- 1000px 以下，内容左右内边距缩为 24px。
- 640px 以下，外距与面板间距 4px，内容内边距 16px，顶部栏高度 56px，图标栏宽 56px。
- 移动端输入框文字至少 16px，输入区底部包含安全区留白。
- 对话区高度使用顶部栏和外距变量计算，避免切换侧栏或屏幕尺寸后出现额外滚动。

### 维护

调整对应组件规则，不追加整套主题覆盖。修改尺寸时同步核对默认、聚焦、展开和移动端状态，并更新本规范。

图标语义：对话 MessageSquare、项目 Folder、发展方向 Compass、每周回看 CalendarCheck2、记忆 Brain。历史对话使用 History，与每周回看区分。悬停允许 1px 轻微位移，减少动态效果设置下关闭位移。
