# 广莫设计规范

## 1. 适用范围与维护原则

本文定义 Web 共用设计规则；业务交互见[对话页面规范](../docs/对话页面规范.md)，开发与文档维护规则见 [AGENTS.md](../AGENTS.md)，原型能力和验收状态见[原型说明](../prototype/README.md)。

- 正文为已确认要求；待确认事项集中在第 12 节或页面规范，确认前保持现状。正式应用的实现缺口集中在第 10 节。
- 本文定义设计用途、共用关系和交互要求；已声明的变量值以对应源码为准。尚未实现且需要明确的数值约束在本文保留。源码接入与验收通过分别记录。
- 排版、间距、布局及通用圆角值见 [tokens.css](../apps/web/src/app/tokens.css)；补充状态色、输入背景、聊天圆角、轻投影、边框／焦点、控件／列表／开关尺度及动效见原型 [theme.css](../prototype/theme.css)。正式 `--radius-nav`、`--radius-panel` 暂位于 [globals.css](../apps/web/src/app/globals.css)。迁移变量时更新来源，不保留两份数值规范。

## 2. 产品气质

平静、清晰、留白充足的个人 Agent 工作台。用间距和轻分隔建立层次，减少独立卡片及嵌套背景块。不使用排行榜、连续打卡或惩罚性提醒；用户可以修改、拒绝或暂停建议。

## 3. 颜色与主题

- 使用中性黑白灰，浅色主区为冷白，交互与导航不另加彩色强调；亮暗主题的前景、背景成对维护。
- 颜色按“基础中性色阶 → 语义变量 → 组件”组织。下表记录已确认的语义角色与配对，变量的新增与复用按第 10 节。
- 主题入口位于侧栏底部，各页面可访问；本地保存选择并在刷新后恢复。

### 语义颜色用途

| 用途 | 变量／配对 |
|---|---|
| 外围／主区／侧栏 | `--outer`／`--surface`／`--sidebar`；侧栏在两种主题均引用 `--surface` |
| 输入区域 | `--input`；单行、多行、聊天、搜索、日期和下拉统一使用，浅色为浅灰 |
| 内容分组 | `--panel` |
| 正文／次要文字／弱提示 | `--text`／`--secondary`／`--muted` |
| 分隔线／输入边界 | `--line`／`--input-line` |
| 悬停／持续选中／焦点 | `--hover`／`--selected`／`--focus`，各自独立 |
| 主要按钮 | `--strong` + `--on-strong` |
| 次级有底色按钮、新建入口 | `--soft-bg` + `--secondary` |
| 默认头像 | `--avatar-bg` + `--secondary` |
| 引用定位高亮 | `--reference-highlight-bg` + `--text` |
| 滚动条 | `--scrollbar-thumb`／`--scrollbar-track` |

后三种非选中背景（按钮、头像、引用）共用基础色阶值，不能借用 `--selected`。滚动条用于普通滚动表面，透明轨道按实际底色检查对比度。浅色标签页使用灰色底槽、白色选中项。

### 按下状态颜色

普通控件使用 `--pressed-bg` + `--text`，主要按钮使用 `--pressed-strong-bg` + `--on-strong`。仅用边界反馈的控件不必新增背景。

### 禁用状态颜色

| 用途 | 变量 |
|---|---|
| 文字、图标及关联选择标签 | `--disabled-foreground` |
| 已有实底控件背景 | `--disabled-bg` |
| 输入框、多行文本框、选择框背景 | `--disabled-input-bg` |
| 已有边界 | `--disabled-border` |

不整体降低透明度，不新增背景或边框；原本透明的控件保持透明。输入区域仍需与页面区分。禁用时关闭可用状态的悬停反馈，保留原名称，不额外添加“不可用／不可编辑”文案。

### 浮层背景

浅色浮层使用主区表面色；暗色浮层优先使用比主区略亮的面板色。

组件展示页弹窗面板采用磨砂玻璃：以对应主题浮层色生成 `--dialog-glass-bg` 半透明背景，模糊用 `--dialog-glass-blur`；页面遮罩用 `--dialog-backdrop-bg` 与 `--dialog-backdrop-blur`。不降低文字和控件透明度。不支持背景模糊或系统要求减少透明效果时，面板回退实色浮层背景。

## 4. 字体与排版

使用系统无衬线字体，不使用宋体、水墨或仿纸纹理。紧凑及禁用状态不缩小字号；手机标题在第 9 节小屏断点切换，输入字号不随屏宽变化。

| 用途 | 字号 | 行高 | 字重 |
|---|---|---|---|
| 欢迎标题 | `--text-welcome`／手机 `--text-welcome-mobile` | `--leading-title` | `--weight-medium` |
| 内容页标题 | `--text-page-title`／手机 `--text-page-title-mobile` | `--leading-title` | `--weight-semibold` |
| 区块标题 | `--text-section-title` | `--leading-standard` | `--weight-semibold` |
| 对话、阅读正文 | `--text-body` | `--leading-reading` | `--weight-regular` |
| 输入 | `--text-input` | `--leading-standard` | `--weight-regular` |
| 按钮、菜单、列表 | `--text-control` | `--leading-standard` | `--weight-medium` |
| 辅助说明、时间 | `--text-caption` | `--leading-standard` | `--weight-regular` |

组件展示页例外：分类名用正文／标准行高／medium；输入、日期及下拉（含选项）用控件字号／标准行高／regular；表格、输出、工具提示、标签简短状态和消息提示用控件字号；尺寸注释用辅助层级。弹窗标题仍用区块标题。

## 5. 间距与布局

- 固定图标窄侧栏使用 `--rail-width`，不展开、不放 Logo；顶部为导航，底部为连接器、账户和主题入口。
- 侧栏与主区为独立圆角面板；外距 `--frame-gap`，面板间距 `--panel-gap`，桌面顶栏高度 `--header-height`。页面决定是否使用顶栏。
- 单栏阅读、表单和普通列表以 `--content-width` 限宽居中，空间不足时收窄；多栏工作区及宽表格可占主区可用宽度，由页面规范说明。对话另用页面规范中的宽度。
- 内边距按第 9 节；面板外距不用于组件内部。同用途用同尺度，不随意增加相近数值。

| 变量 | 用途 |
|---|---|
| `--space-1` | 紧密关联控件；窄栏左右留白、底部辅助入口与账户间距 |
| `--space-2` | 图标与文字、分组、相邻操作 |
| `--space-3` | 常规按钮／容器内边距、文字组间距 |
| `--space-4` | 表单／面板内边距、相邻内容组 |
| `--space-5` | 较大区块间距 |
| `--space-6` | 大区块留白 |
| `--space-7` | 大区块之间的留白 |
| `--space-8` | 特殊展示，常规工作台不默认使用 |

导航项不加额外间隔；其他内容按关联程度分组。

## 6. 圆角、边框与阴影

### 圆角

圆角矩形采用苹果风格连续曲率；圆形、胶囊、Logo 和图标原始路径保留形状。

| 类型 | 圆角 |
|---|---|
| 小按钮、工具入口 | `--radius-button` |
| 导航状态底块 | `--radius-nav`，悬停与选中一致 |
| 浮层 | `--radius-md` |
| 侧栏、主区 | `--radius-panel` |
| 单行输入 | `--radius-round`，胶囊形 |
| 独立多行输入、消息气泡、内容分组 | `--radius-lg` |
| 含操作栏的聊天输入区 | `--radius-composer`，圆角矩形 |
| 头像 | 圆形 |
| 快捷文字入口 | 胶囊形，仅悬停显示背景 |

### 边框与焦点

- 控件边界与分隔线用 `--border-width` 实线；焦点用 `--focus-width` 独立轮廓，不占布局空间。
- 例外：单行文本输入（含搜索）及独立多行文本框以背景区分区域，常态和聚焦均不显示描边、轮廓或阴影。
- 悬停、按下仅改变颜色，边框宽度稳定。

### 阴影

| 用途 | 阴影 |
|---|---|
| 主区、侧栏、大输入框、标签选中项 | `--frame-shadow` 轻投影 |
| 菜单、下拉浮层、弹窗 | `--popup-shadow` 较明显投影 |

两组阴影均适配亮暗主题，不互相替用；浮层不使用黑色边框。其他用途需说明理由。

## 7. 图标与品牌

- 功能图标统一 Phosphor 官方 regular／fill，不混用其他库、Emoji、单字或自绘实心图标。
- 保留 256 × 256 `viewBox` 与路径比例；侧栏优先柔和、圆形轮廓。不拉伸、旋转或添加装饰渐变、阴影。
- 可按内部留白等比校准大小，保持重心、粗细协调及 regular／fill 切换稳定；布局占位和点击范围不随校准变化。

### 尺寸与点击区域

| 位置 | 图形 | 字重 | 点击范围 |
|---|---|---|---|
| 主导航 | 20 × 20px | 默认 regular，当前页 fill | 至少 44 × 44px |
| 顶栏、附件、历史、连接器 | 18 × 18px | regular | 紧凑或触屏规格 |
| 附属箭头 | 12 × 12px | regular | 随所属按钮 |

导航悬停／选中底块为 36 × 36px，位于点击区中央。其他控件按指针类型使用 `--control-compact` 或 `--control-touch`，不只按屏宽判断；相邻点击范围不得重叠。

### 功能映射

| 功能 | 图标 |
|---|---|
| 对话 | `chat-circle` |
| 项目 | `circles-four` |
| 学习 | `student` |
| 发展方向 | `compass` |
| 每周回看 | `check-circle` |
| 记忆 | `brain` |
| 已连接的生活 | `link` |

### 导航状态

默认用次要文字色，悬停／当前页用正文色；当前页用同名 fill。悬停仅改变颜色，不位移、缩放或改变点击区。

### 品牌

Logo 与品牌颜色见[品牌说明](README.md)，保持轮廓和比例，不以功能图标或单字代替。

## 8. 组件与交互

### 输入法与键盘

公共输入组件支持组词状态和键盘事件。普通多行编辑器 Enter 换行；对话提交规则见页面规范。

### 多行输入

按内容增高、删除后缩回、达到上限后内部滚动；普通编辑器可手动调整高度。

### 复选框

18px 方形外框、5px 连续圆角，内部为 14px Phosphor regular `check`，不用旋转边框拼勾。保留原生 checkbox 与标签的点击、键盘、选中语义；勾形为装饰，不拦截点击。

### 开关

- 尺寸用 `--switch-width`、`--switch-height`、`--switch-thumb-size`、`--switch-thumb-inset`；`--switch-thumb-travel` 按边框和内距计算位移。圆点垂直居中，两端留白对称。
- 标签、轨道居中对齐，轨道不伸缩；整行可点击，触屏行高用 `--control-touch`。
- 禁用关闭用 `--disabled-bg`，禁用开启用 `--switch-disabled-on-bg`，圆点用禁用前景，保留位置区别且不加状态文字。保留原生 disabled、checked 与 switch 语义。

### 组件展示页密度

桌面左侧分类、右侧示例，窄屏上下排列；用间距和轻分隔分组，尺寸示例底部对齐，输入示例同宽。

| 对象 | 尺度 |
|---|---|
| 普通按钮、单行输入、日期 | 最小高度 `--control-compact`，左右 `--space-3`；图标按钮为方形，箭头侧预留 `--space-6` |
| 短选项下拉示例 | 可用与禁用示例同宽，使用 `--gallery-select-width`，不超过容器；触发器最小高度用 `--gallery-select-height`，选项用 `--gallery-select-option-height`，触屏均改用 `--control-touch`；选项之间间距 `--space-1`；触发器上下内边距 `--space-1`，选项为其一半，左右均为 `--space-3`，触发器箭头侧预留 `--space-6` |
| 普通多行示例 | 最小高度 `--gallery-textarea-height`，上下 `--space-3`、左右 `--space-4`；聊天示例保留各自尺寸 |
| 标签与输入／同组控件及示例行／尺寸示例 | 间距分别 `--space-2`／`--space-3`／`--space-4` |
| 分组／弹窗 | 组上下留白、弹窗内边距均为 `--space-5` |
| 标签页 | 按钮最小高度 `--gallery-tab-height`，触屏改用 `--control-touch`；按钮上下内边距为 `--space-1` 的一半；底槽随内容收窄，内边距与按钮间距均为 `--space-1` |
| 紧凑表格 | 单元格最小高度 `--control-compact`，保留可读行高 |
| 触屏输入、选择标签行 | 最小高度 `--control-touch` |

### 通用列表密度

单行最小高度 `--list-single`、垂直居中；多行最小高度 `--list-multiline`，随内容增高、不裁切。左右留白 `--space-3`，触屏点击范围另按第 7 节检查；分组和排序由页面规范定义。

### 标签页状态

组件展示页标签按钮在默认、悬停、选中与按下状态均无描边；悬停和按下使用正文色文字，保留选中底块，宽度和尺寸不变。键盘操作保留独立焦点提示，选中与焦点可同时辨认。

### 进度条

组件展示页进度条高度用 `--gallery-progress-height`，百分比文字用辅助说明字号 `--text-caption`。轨道与填充均无描边、无阴影，使用 `--radius-round` 胶囊圆角；轨道用 `--input`，填充用 `--strong`，适配亮暗主题。保留原生进度语义及可访问名称。

### 滑块

组件展示页滑块轨道高度用 `--slider-track-height`，无描边、胶囊圆角，未填充部分用 `--input`，填充部分用 `--strong`。拖动圆点外径用 `--slider-thumb-size`，填充用 `--strong`，以两倍 `--border-width` 的 `--surface` 外圈和 `--frame-shadow` 轻投影与轨道区分；圆点保持正圆，不随悬停或按下缩放。透明点击区域高度按紧凑／触屏规格，保留原生拖动、方向键及焦点语义。数值用 `--text-caption`、次要文字色及等宽数字，并预留完整百分比宽度。

### 组件状态

基础组件管理适用的默认、悬停、选中、焦点和禁用状态及语义，业务页决定何时触发。选中与焦点可共存。

| 状态 | 要求 |
|---|---|
| 按下 | 轻微背景或边界变化，位置和尺寸稳定 |
| 加载 | 原位进度提示，尺寸稳定，防止重复提交 |
| 错误 | 就近说明原因和修正方式，保留输入 |
| 成功 | 轻量就地反馈，不默认弹窗打断 |

### 动效

| 场景 | 效果与变量 |
|---|---|
| 控件、导航、表格行、单选圆点 | 颜色或圆点显隐用 `--duration-color` |
| 菜单、浮层 | 淡入淡出，`--duration-popup` + `--ease-popup`，不弹跳；淡出渐进增强 |
| 组件页标签选中底块 | 用 `--duration-popup` + `--ease-popup` 滑到当前标签，并平滑适配其宽高；不弹跳 |
| 组件页消息提示、标签内容 | 同上时长与缓动，保留淡入和轻微上移 |
| 主题 | 扩散，`--duration-theme` + `--ease-theme`；不支持时直接切换 |

系统开启“减少动态效果”时跳过非必要动画，保留最终状态和反馈。

## 9. 响应式与无障碍

### 响应式

| 视口宽度 | 内容左右内边距 | 其他调整 |
|---|---|---|
| ≥ 1000px | `--page-inset` 桌面值 | — |
| 640px 至不足 1000px | 16px | — |
| < 640px | 12px | 外距和面板间距 4px，顶栏 48px，侧栏宽度不变 |

手机底部聊天输入区由外层在常规留白之外叠加一次 `env(safe-area-inset-bottom, 0px)`。

### 键盘与可访问语义

支持键盘操作和可见焦点（第 6 节输入例外除外）；当前页用 `aria-current="page"`，不可用操作设置 `disabled`。纯图标按钮提供 `aria-label`，有文字按钮的图标标为装饰，图标不单独获得焦点。错误不只靠颜色表达。

### 对比度

在实际背景检查：普通文字（含提示、时间、占位文字）至少 4.5:1，大号文字至少 3:1；必要图标、控件边界及焦点至少 3:1，装饰分隔线可更淡。参考 [WCAG 文字](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[非文字](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)与[颜色使用](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)。

## 10. 样式实现约定

- `tokens.css` 管基础值，`globals.css` 映射 Tailwind 工具类并负责重置、字体和底色；[基础组件](../apps/web/src/components/ui)管理外观、尺寸和状态，业务页负责布局组合。
- 优先复用用途相同的变量和工具类。多个使用位置需要联动调整，或某个设计角色需要按主题、状态独立调整时，可新增变量。单个组件的局部尺寸与样式留在组件内。已确认的独立角色即使当前值相同，也各自保留变量。
- 间距映射按用途和实际数值核对，不按数字名机械替换。
- 连续曲率用 `--corner-shape`、`corner-shape: squircle`，在 `@supports` 内覆盖元素及伪元素；不支持时回退普通圆角。正式圆形／胶囊标记 `data-corner="round"`，此为 Web 近似。[参考](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/corner-shape)
- Web 图标只从 `@/components/ui/Icon` 导入，仅 `Icon.tsx` 直引 Phosphor，由 ESLint 限制。校准统一用 `calibrateIcon`：`CirclesFourIcon` 1.18；`BrainIcon` regular 0.9、fill 0.95；其他不缩放。调用方控制尺寸与字重，按钮／链接控制状态；不同尺寸与字重须检查效果。[SVG 与许可证](icons/phosphor/)
- 允许内容、测量和位置驱动的动态样式；保留 Textarea 自动高度与清理、图标校准及主题扩散位置计算，仍遵守设计变量和状态约束。

## 11. 验收要求

在亮暗主题、桌面／触屏及目标浏览器检查：

- 控件各适用状态、加载防重复提交、错误输入保留、语义和点击范围。
- 实际背景上的对比度、选中与焦点共存；边框宽度及布局稳定，半透明浮层在深浅内容上可读且层级清晰。
- Tab 顺序、按钮名称、输入法、多行编辑、长内容、输入增高／缩回／上限滚动、列表增高和不同屏宽滚动边界。
- 动效及减少动态效果开关；图标 regular／fill 的大小重心、圆角回退。
