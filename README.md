# 广莫 / Guangmo

> 为每个人的自由而全面的发展。

广莫是一个个人 Agent，帮助用户管理、理解与推进真实生活，同时保留自己的判断与选择。

名字取意于《庄子·逍遥游》中的“广莫之野”。中文名称为“广莫”，英文名称为“Guangmo”，代码与包名使用 `guangmo`。
